# Aprenda Go com Testes

Repositório com meus exercícios seguindo o tutorial [Learn Go with Tests](https://quii.gitbook.io/learn-go-with-tests/).

## 📚 Sobre

Este repositório documenta a nossa jornada aprendendo Go através de Test-Driven Development (TDD), seguindo o tutorial de Chris James.

**Recursos:**
- [Versão em Português](https://larien.gitbook.io/aprenda-go-com-testes/)
- [Versão em Inglês (original)](https://quii.gitbook.io/learn-go-with-tests/)

## Metodologia

Cada exercício segue o ciclo TDD:

1. **🔴 Red** - Escrever um teste que falha
2. **🟢 Green** - Escrever código mínimo para passar
3. **🔵 Refactor** - Melhorar o código mantendo os testes verdinhos

## 🚀 Como Executar

### Rodar testes 
```bash
cd pasta-do-capitulo
go test
```

### Rodar testes com detalhes
```bash
go test -v
```
